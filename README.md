# ProcastiNO

ProcastiNO is a doodle-themed anti-procrastination app built with React + Vite.

## What it does

1. **Task intake on a doodle board**  
   The character asks for your tasks and preferred timeframe.
2. **Mind-cleanup scene**  
   A playful animation shows the character "organizing your thoughts" like cleaning a messy room.
3. **Timetable output on the same board**  
   Your day plan appears directly on the same planning board with task blocks and reset breaks.

## Tech

- React
- Vite
- rough.js for hand-drawn doodle visuals

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
